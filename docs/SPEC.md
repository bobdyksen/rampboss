# Ramp Boss — Product Specification (condensed)

Working title: Ramp Boss  
Genre: Arcade / time management / airport operations  
Platform target: iOS and Android  
Orientation: Landscape  
Session: 5–15 minutes  
Input: Touch

## Fantasy

You are the Ramp Boss. Keep the airport moving.

The game should feel like an arcade game, not a certification exam. Real turnaround structure stays. Perfect procedural accuracy does not.

## Pillars

1. Controlled chaos — slightly overwhelmed, able to recover, “that was close.”
2. Easy to understand, hard to master — assign limited resources against departure times.
3. Aviation authenticity without simulator complexity.
4. Everything visible — the ramp is the interface. Vehicles drive. Bags move. Bridges connect.

## MVP (this repo)

One ramp, two gates, regional jet + narrowbody.

Services: jet bridge, baggage unload, fuel, cleaning, baggage load, boarding, pushback.

Equipment: belt loader, bag tractor, fuel truck, cleaning van, pushback tug.

Success test: aircraft arrives → ramp gets busy → player dispatches → bottleneck appears → countdown tightens → tug connects → score explodes → the next inbound makes the player wince.

## Later, not now

Widebodies, deicing, weather, licensing, airport building, endless leaderboards, photorealism.

Every later feature still has to create a decision, a tradeoff, time pressure, a resource conflict, or a visual payoff.
